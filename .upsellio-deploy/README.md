# Upsellio chat integration
The production WordPress installation at https://upsellio.pl has Upsellio DevOps Bridge 1.1.0 and Upsellio Rank Math REST Bridge 1.0.0.
## Setup
Open https://upsellio.pl/wp-admin/tools.php?page=upsellio-devops-bridge as administrator. Leave the backup path blank to try creating a validated private 0700 directory outside the document root. Automatic deployment is opt-in. Enable it only after checking trusted repository writers and protections for main and upsellio-deploy. A custom existing private backup directory can be specified if auto-detection fails.
## Deployment protocol
This branch carries requests only. Edit the source theme on a feature branch, review, then merge the approved changes into main. Read the live status and existing file SHA-256 values from page 947 in edit context (meta.upsellio_devops_status). Use only a reviewed commit on main and a new request_id. Submit .upsellio-deploy/request.json with schema 1, a unique 12-80 character request_id, a full 40-character commit SHA and files array (1-12 objects with path relative to wp-content/themes/upsellio, before and after SHA-256). Paths must match the plugin allowlist: existing presentation templates and CSS/JS files only; no functions.php, inc/, CRM, vendor, config, deletions or additions. No secrets or unpublished content in this public repository. 
The bridge validates the commit ancestry, checks current and proposed hashes, prepares backups, lints PHP, switches existing files, clears cache and tests homepage HTTP. It stops on a mismatch and tries rollback if a deployment fails. Always check final status plus a separate functional and visual test of changed pages. Do not report a deployment as complete merely because the GitHub request was committed. Reset request.json to {"schema":1,"action":"idle"} after successful verification. Rollback from the WordPress admin panel disables automation.
## Rank Math
Read and write SEO fields using WordPress content-items-get/update with post_type post or page, context edit on reads, and meta containing rank_math_title, rank_math_description, rank_math_focus_keyword, rank_math_facebook_title/description and rank_math_twitter_title/description. Preserve existing unrelated content and metadata. A stored rank_math_seo_score may be available in edit responses, but never write a fabricated score; verify recalculation in Rank Math's native analysis. PHP templates with empty post content require separate rendered-content review. Use https://rankmath.com/kb/score-100-in-tests/ as the editorial checklist.
